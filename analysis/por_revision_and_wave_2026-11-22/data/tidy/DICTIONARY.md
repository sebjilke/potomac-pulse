# Data dictionary

Generated by tools/03_build_tidy.py (tools/dictionary.py). All times are ISO 8601 UTC ending in Z unless a column says "epoch ms" (the raw log value, integer milliseconds since 1970-01-01 UTC), and every epoch column has a companion `_utc` column. Blank = missing. Booleans are 1/0. SU = `netlify/functions/scheduled-update.js` in the PotomacPulse repository (line numbers as of the checked-out copy of 2026-11-22). Job-log meanings are quoted from the code that writes the field; where the code only passes a value through, the meaning is that of the source variable.
